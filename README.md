# Scholar, Family & Community School Support (FSS + KSSN)

How GRPS Family Support Specialists (FSS) and Kent School Services Network (KSSN) coordinators work together. It's a static site published with GitHub Pages.

**Live:** https://melatkins2-ops.github.io/grps-fss-kssn-integration-test/

## Files
- `index.html` — the guide: Start Here, How We Work Together, Work a Situation, Tools & Resources
- `workspace.html` — Support workspace (demo mode on GitHub Pages; sample data saved in the browser only)
- `apps-script/` — the live version that runs inside the "FSS + KSSN Support Tracker" Google Sheet (Code.gs + Index.html)
- `src/` — workspace source and data; run `python3 build_workspace.py` to rebuild both versions
- `downloads/` — 12 tools as Word files, each in English (`_EN`) and Spanish (`_ES`); opened from Tools & Resources
- `attendance_qa.html` — manual QA checklist for the live site
- `QA_SUMMARY.md` — notes from the last build
